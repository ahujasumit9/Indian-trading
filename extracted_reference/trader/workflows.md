# Workflow orchestration

Adapted from the original Trader skill's handoff model.

## Research-to-trade
`analyst -> screener -> budget -> options-intelligence -> risk -> broker-preview -> explicit-approval`

## Intraday monitoring
`market-data -> scanner -> news -> entry-check -> exit-plan -> alerts -> journal`

## Portfolio maintenance
`portfolio-import -> tax-ledger -> rebalance-proposal -> risk -> approval`

## Indian replacement for Pelosi tracker
Monitor public Indian institutional/regulatory information where lawfully available:
- FII/DII activity published by exchanges/depositories
- NSE/BSE corporate announcements and filings
- SEBI orders/circulars and public disclosures
- Bulk/block deal disclosures
This is not equivalent to US congressional trade disclosures and must not be represented as insider-trade tracking.
